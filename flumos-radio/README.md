# Flumos Radio

Локальный прототип авторского онлайн-радио. Четыре отдельных канала: Ambient, Chill, Jazz Ballads и Cosmic. Cosmic — для оригинальных композиций с психоделическим роком, мистической электроникой и атмосферным звучанием. Каждый слушатель получает свою очередь треков и может переключить композицию. Live — общий аудиопоток с текстовым чатом. Интерфейс на русском, вход слушателям не нужен.

## Запуск на Windows

Нужен Node.js 20 или новее. В папке `flumos-radio`:

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

Замените `RADIO_ADMIN_PASSWORD` на длинный личный пароль. Откройте `http://127.0.0.1:4178/`; пульт автора — `http://127.0.0.1:4178/admin`. Пароль хранится только в локальном `.env`, который Git не отслеживает. Для запуска на другом компьютере со своей копией репозитория повторите настройку `.env`.

## Музыка и управление

- В пульте автора добавьте MP3, название, канал и необязательную обложку PNG/JPG/WebP. Новые треки сразу появляются на сайте после обновления страницы.
- В разделе «Добавить файлы или папку» выберите режим: один или несколько файлов либо папку целиком. Затем укажите канал и исполнителя. MP3 из выбора, включая вложенные папки, загружаются по очереди. Название берётся из имени файла; PNG/JPG/WebP с тем же именем становится обложкой (в папке обложка должна лежать рядом с MP3). Треки с уже существующим названием в выбранном канале пропускаются. Пульт показывает ход загрузки и ошибки каждого файла.
- Музыкальные файлы лежат в `media/`. MP3 настроены для Git LFS: после проверки прав их можно добавить командой `git add flumos-radio/media flumos-radio/tracks.json flumos-radio/recordings.json` из корня репозитория и отправить вместе с кодом. Небольшие обложки добавляются обычным Git. На другом компьютере потребуется Git LFS и `git lfs pull`. До первого добавления файлов в Git они остаются только на флешке.
- При удалении трека из каталога MP3 остаётся в `media/` как исходник. Удаление файла вручную нужно делать только после резервной копии.
- Для нового радио нужны самостоятельные композиции, разрешённые к публикации. Старые файлы Enigma Style Mix в каталог не добавлены.

## Live

В первой локальной версии Live принимает готовую HTTPS-ссылку на аудиопоток. Для теста на этом же компьютере разрешена ссылка `http://127.0.0.1:...`. Источник потока (например, Icecast) настроим при переходе на VPS. Включайте статус Live в пульте после запуска источника. Чат открыт только во время Live; администратор может удалять сообщения и блокировать отправителя на время текущего эфира. Для архива загрузите MP3 записи после эфира.

## Проверка и перенос

```powershell
npm test
```

На другом компьютере: `git clone` или `git pull` ветки `flumos-radio`, затем `git lfs pull`, создать `.env` и выполнить `npm start`. Если новые MP3 ещё не были добавлены в Git LFS, перенесите `media/` с этой флешки. Подробное состояние проекта и следующие шаги — в `HANDOFF.md`.

Для VPS понадобится HTTPS-прокси, отдельный источник Live-аудио, защищённые резервные копии `media/`, `tracks.json`, `recordings.json` и `runtime/`. Текущие сайты FLAKS не затронуты.
