Пульт автора.

Здесь вы добавляете музыку, включаете Live и модерируете чат. Доступ есть только у владельца.

Вход

Добавить композицию

Для радио нужен MP3. Обложка PNG, JPG или WebP необязательна. Публикуйте только треки, права на которые проверены.

Live

Начните передачу звука, затем включите статус эфира. При выключении чат закрывается.

Запись эфира

После Live загрузите MP3, который хотите оставить в архиве.

Добавить файлы или папку

Выберите один или несколько файлов либо папку целиком. MP3 загрузятся по очереди в выбранный канал; названием станет имя файла. Обложка подхватится, если у неё то же имя, а в папке она лежит рядом с MP3. Остальные файлы пропускаются.
