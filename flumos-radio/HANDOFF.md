# Передача работы: Flumos Radio

Обновлено: 20 октября 2026.

## Решения пользователя

- Сначала создать и посмотреть радио на этом компьютере. Затем заниматься VPS и сайтами FLAKS.
- Имя и артист: **Flumos Radio / Flumos**. Русский интерфейс. Бесплатно и без регистрации, без рекламы.
- Каналы: Ambient (спокойный фон), Chill (downtempo/lounge), Jazz Ballads (лирические баллады), Cosmic (психоделический рок, мистическая электроника и атмосферные путешествия), Flumos Spectrum (авторские песни и музыка разных жанров). Cosmic добавлен по просьбе пользователя для музыки в духе Pink Floyd и Enigma; название предложено как рабочее и может быть изменено.
- Музыка своя, создаётся и отбирается Flumos самостоятельно или с помощью Suno; участие Suno указано открыто. Старый Enigma Style Mix не включать до отдельной проверки.
- Для каждого канала цель 15–25 отобранных треков, запускать каналы по мере готовности. Пользователь готовит новые композиции в Suno; текущий тариф ещё не известен.
- У каждого слушателя своя очередь и свободный Skip. Обычные каналы без голосовых вставок.
- Live — отдельный общий аудиоканал с голосом ведущего и текстовым чатом по гостевому имени. Чат только во время эфира. Записи избранных эфиров доступны позже.
- Первые слушатели — знакомые и тематические сообщества. Ключевой признак спроса — возвращение к прослушиванию. YouTube пока не используется.
- Ориентир по инфраструктуре: OVHcloud VPS-2 в Европе, бюджет сервер+трафик до €20/мес. Новый домен позже. Страна оформления ещё не выбрана.

## Что реализовано локально

- `server.mjs`: сайт и API без внешних пакетов; защищённый вход автора, загрузка MP3 и обложек, каталог, выдача аудио с поддержкой Range, Live-статус, чат и модерация, архив записей, примерные показатели слушателей.
- `public/`: адаптивная главная страница, отдельные карточки каналов, плеер, Live, чат и пульт автора.
- В пульте можно добавить один трек с ручным названием либо выбрать один/несколько файлов или целую папку с MP3 для последовательной загрузки в один канал. В массовом режиме имена файлов становятся названиями; одноимённые обложки подхватываются.
- `tracks.json` и `recordings.json`: отслеживаемые метаданные. `media/*.mp3` настроены для Git LFS; одобренный пользователем R1 уже отправлен в GitHub. `runtime/` и `.env` остаются локальными.
- `tests/server.test.mjs`: проверка API без изменения реального каталога.

## Следующие шаги

1. Пользователь смотрит локальный сайт по адресу `http://127.0.0.1:4178/` и выбирает собственные MP3 для Ambient, Chill, Jazz Ballads, Cosmic и Flumos Spectrum. Сейчас в каталоге есть R1 в Ambient; пустые каналы показывают «Готовится к эфиру». Уточнить тариф и разрешённые скачивания Suno перед публикацией новых треков. Проверить права на каждый файл.
2. Настроить реальный источник Live-аудио и проверить микрофон/музыку с этого компьютера. В проекте уже есть приём ссылки на поток, но сам поток не создаётся Node-приложением.
3. После локальной проверки заказать VPS и домен, настроить HTTPS, резервные копии и перенести радио. Только затем рассматривать перенос сайтов FLAKS по одному с проверкой форм заказов.

## Важное для другого компьютера

- Git-репозиторий: `https://github.com/Flumos1/Youtube_muz.git`, ветка `flumos-radio`, папка `flumos-radio`.
- Если используется **эта же флешка G:**, локальные MP3 и `.env` остаются в ней. Буква диска на другом компьютере может измениться; запускайте команды из папки проекта.
- При клонировании на другой компьютер выполните `git lfs pull` для сохранённых MP3. Если вы ещё не коммитили новые MP3, перенесите `media/` отдельно. Секретный `.env` всегда создаётся заново по образцу либо переносится безопасно отдельно от Git.
- Ветка `flumos-radio` сохраняет исходники и метаданные радио; перед переносом на другой компьютер проверить, что последний коммит отправлен на GitHub.
